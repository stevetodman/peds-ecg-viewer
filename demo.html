Viewer help and limitations

Supported

  • Review repository JSON records and local JSON files.
  • Adjust display speed, gain, grid, and zoom.
  • Export a local PNG or use the browser print dialog.
  • Explicitly save one exact patient-and-waveform snapshot in page memory until you clear it or leave this page.

Not supported

  • Clinical diagnosis, source-label verification, signing, billing, or EHR integration.
  • Automatic or external ML/AI analysis.
  • Validated interval, axis, or rhythm measurement unless supplied with provenance by the source.
